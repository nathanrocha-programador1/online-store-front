# Página Web – Online Store

Projeto de página web desenvolvido em HTML, CSS e JavaScript que apresenta uma loja virtual com variedades de produtos em destaque.

A proposta é criar uma página moderna, interativa e visualmente atrativa para apresentação de produtos de tecnologia, utilizando animações, transições e efeitos visuais.

Esta página pode ser utilizada como base para portfólio pessoal, apresentação de projetos web ou estudos de desenvolvimento Front-end.
